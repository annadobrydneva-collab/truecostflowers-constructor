# TrueCostFlowers — конструктор композиций

## Основная версия

**v3.2-rc3** — утверждена владельцем продукта в качестве основной версии 7 ноября 2026 года.

- Приложение: https://annadobrydneva-collab.github.io/truecostflowers-constructor/
- Исходный код основной версии: `main/index.html`
- Предпросмотр: https://annadobrydneva-collab.github.io/truecostflowers-constructor/preview-v3.html
- Разработка и последующие тесты: отдельные ветки / версионированные изменения.

Основные возможности v3.2-rc3: выбор и смена основы свайпом без удаления композиции, автоматическая расстановка, масштаб и жесты, библиотека 3×3, управление слоями и стеблями, редактирование количества цветов, Undo/Redo, отражение выбранного растения, удаление через крестик, предварительный калькулятор, предупреждение о бюджете меньше 3 500 ₽.
